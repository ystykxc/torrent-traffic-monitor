# Torrent Traffic Monitor · 下载器流量统计

一个面向多下载器 PT / NAS 场景的轻量流量监控工具。它只采用下载器**持久累计计数器的差值**统计上传 / 下载流量，不使用「速率 × 时间」估算，因此日 / 周 / 月 / 年报表与汇总卡片完全对账。全部数据存放在一个 SQLite 文件中，前端为零外部依赖的原生 SVG 图表。

本项目提供**两种部署形态**，共用同一套流量统计核心，代码统一托管在本仓库（不拆分仓库）：

| 部署形态 | 当前版本 | 适用场景 | 说明入口 |
|---|---|---|---|
| 独立 Docker 版 | **v50** | 飞牛 NAS / x86 主机独立运行，自带 Web UI、账户体系、PWA | [docker/README.md](docker/README.md) |
| MoviePilot V3 插件版 | **v1.0.32** | 已安装 MoviePilot V3，作为本地插件安装，复用宿主下载器配置与认证，支持定期通知 | [moviepilot/README.md](moviepilot/README.md) |

## 功能概览

- **四周期汇总**：今日 / 本周 / 本月 / 本年上传量与下载量，历史数据可回看。
- **双图表**：实时速率折线图（按固定粒度聚合、保形平滑）与流量统计堆叠柱状图（按自然周期分桶、按下载器分段堆叠）；支持横向拖动回看多个窗口，选择与位置自动记忆。
- **多下载器**：自动 / 手工接入任意数量 qBittorrent、Transmission；展示实时速率、在线状态、限速、版本、剩余空间与种子状态统计。
- **统计口径严谨**：只用累计计数器差分，跨午夜 / 重启 / 断线不丢不重。
- **安全与易用**（Docker 版）：账户登录、会话绑定、全局限流、SSRF 防护、审计日志；深浅双主题、手机端自适应、安卓 PWA。
- **原生集成**（插件版）：设置项全部落在 MoviePilot 原生配置面板，下载器直接读取宿主已接入配置，支持定时流量通知（含微信排版优化）。

## 如何选择

- **已经在用 MoviePilot V3** → 选插件版：无需单独容器与账户，下载器配置自动复用，还能把流量报表定时推送到通知渠道。
- **想要完全独立运行** → 选 Docker 版：一个容器搞定，自带登录与 PWA，局域网内任何设备可直接访问。

两个版本的统计口径与图表实现同源；插件版为保证宿主兼容性，去掉了独立的账户 / 会话 / 限流 / SSRF / 审计 / SSE / PWA 层，认证与边界安全交由 MoviePilot 负责。
