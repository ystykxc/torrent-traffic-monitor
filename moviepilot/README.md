# MoviePilot V3 插件版 · v1.0.32

下载器流量统计的 MoviePilot V3 本地安装插件。由独立 Docker 版 v50 整体迁移而来：认证与边界安全交由 MoviePilot 宿主负责，下载器直接读取宿主已接入的配置，所有设置统一落在 MoviePilot 原生配置面板，并支持定期流量通知。

> 独立 Docker 版请见 [../docker/README.md](../docker/README.md)。

**作者：YST插件定制**

## 安装

1. 下载 [releases/torrenttrafficmonitor_v1.0.32.zip](releases/torrenttrafficmonitor_v1.0.32.zip)（无需解压）。
2. 在 MoviePilot V3 中进入「插件」→「本地安装」，选择该 zip 上传。
3. 安装后在插件列表启用「下载器流量统计」，进入配置面板完成设置。

插件要求 MoviePilot V3；代码内兼容回退到 V2 旧 SDK 路径（`app.plugins._PluginBase`）。

## 与 Docker 版的差异

| 项目 | 独立 Docker 版 v50 | MoviePilot 插件版 v1.0.32 |
|---|---|---|
| 账户 / 登录 / 会话 | 内置 | 由 MoviePilot 宿主负责 |
| 下载器配置 | 手工增删改 | 直接读取 MoviePilot 已接入下载器 |
| 设置入口 | 自带设置页 | MoviePilot 原生 `get_form` 配置面板 |
| 曲线颜色 | 可自定义 | 系统自动分配，支持一键重分配 |
| 主题 | 深浅双主题 | 固定浅色、背景透明（采用宿主底色） |
| PWA / SSE / 限流 / SSRF / 审计 | 内置 | 已移除 |
| 定期通知 | — | 支持，含微信排版优化 |
| 统计口径 | 累计计数器差分 | 同源，完全一致 |

## 配置面板

设置项固定为五行单页平铺（手机端按同顺序单列）：

1. 插件启用开关 + 采样间隔（默认 1 分钟）
2. 定时流量通知开关 + 通知时间（默认每天 22:40）
3. 需要通知的时间范围多选（今日 / 昨日 / 本周 / 本月）
4. 一键重新分配下载器颜色
5. 各下载器启用开关（桌面一行三个）

首次安装默认开启定期通知。

## 监控页面

通过插件的「监控页面」入口打开，展示四周期汇总卡片、下载器卡片与流量统计堆叠柱状图；固定浅色主题、背景透明，手机端紧凑一页展示。

## 定期通知

定期通知把所有勾选的时间范围汇总在一条消息里，各范围用分隔线区分。正文为纯文本表格，上传用 🟢↑、下载用 🔴↓ 区分，并对微信 Markdown 渲染做了居中与对齐适配（v1.0.28~v1.0.32 连续修正）。

示例：

```
今日流量统计（2025-11-15）
+------------+----------------+--------------+
| 合计       |    🟢↑ 1.01 TB |  🔴↓ 2.56 TB |
| QB-01      |    🟢↑ 8.10 GB | 🔴↓ 40.00 GB |
| TR-01      |    🟢↑ 4.24 GB | 🔴↓ 16.78 GB |
+------------+----------------+--------------+
```

## 数据口径

与 Docker 版一致：只采用下载器持久累计计数器的差值，不使用「速率 × 时间」估算。采集分两条节奏——流量统计按配置页「采样间隔」记账，下载器实时速率 / 在线状态按固定 5 秒刷新内存态（不外显设置）。详见 [../docs/流量统计口径深度解析.md](../docs/流量统计口径深度解析.md)。
